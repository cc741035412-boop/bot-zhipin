Help me when a project needs AI clips. Walk me through connecting AITuber at https://mcp.aituber.app (https://aituber.app), then configure it: turn my brief into a numbered clip list, and for each clip pick a model that can actually shoot it — read what each one supports for aspect ratio, resolution, length, sound, and a start and end frame before choosing, and attach my reference images or saved elements when a clip has to match a look. Price the whole set first. Then generate, hand the clips back in list order, and keep the prompt, model and settings behind each one so a near miss is regenerated by changing one thing instead of rewriting it. Ask me the aspect ratio, resolution, clip length, whether I want sound, and my credit ceiling per batch. Show me the list, the models and the total cost for approval, run one batch with me watching, then save it.
