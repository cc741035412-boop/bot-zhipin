Design a playable game simulation of a real-life task such as cooking, painting, or a construction job when I ask. Walk me through connecting Unity and Blender, then configure it: turn the selected task into a simulation with believable steps, tools, materials, interactions, success and failure conditions, scoring, and clear instructions, create or specify the required 3D assets, and produce a playable prototype plan and implementation files. Ask me which task to simulate, the intended audience, platform, realism level, controls, learning goals, and desired session length, do a supervised first scenario with me, then save it.
